# ノウハウ：PowerPoint の表スタイルをテンプレートに焼き込む（2026-09-20）

## 置き場所

- **`ppt/tableStyles.xml`**。スタイルID を `def=` に書くと、そのテンプレートの**既定の表スタイル**になる。
- 人が「挿入 → 表」で作った表にも自動で適用される。**ポリシーがテンプレート側に入る**（テーマ色の並び順と同じ考え方）。
- Figma のデザインファイルには表の機能が無いため、**表の見た目の正はこの XML**（値はトークンから作る）。Figma は見本帳。

## Bigtree Lab 表（確定 2026-09-20）

| 部分 | 見た目 |
|---|---|
| 見出し行 | accent1 の塗り、白の太字、下に 2px の罫 |
| 行の区切り | accent5（グレー淡）の横罫のみ |
| 1行おき | lt2（面）の塗り |
| 1列目 | 太字 |
| 外枠・縦罫 | **なし**（0304 の「枠線で囲まない」規則） |
| 文字 | 補足サイズ 11pt、行間はポイント指定、セル余白 左右12px・上下6px、縦中央 |
| 行の高さ | 56px（＝ PowerPoint 上で約 0.99cm） |

## 踏んだ罠：罫線は「引かない」ことも書く

`insideH`（横罫）だけ指定すると、**外枠と縦罫は PowerPoint の既定の細い罫が出る**。
→ `left / right / top / bottom / insideV` に `<a:ln><a:noFill/></a:ln>` を明示する。
（`tcBdr` の子要素の順番は left → right → top → bottom → insideH → insideV）

同じ性質の落とし穴：テーマ色を省くと Office が勝手に決める、グラフの系列色を省くと accent 順に塗られる。
**「指定しない＝既定が出る」** と覚える。

## 表を使う Organism

- O-B12 データテーブル（標準／高密度）、O-B1 比較テーブル → 図形ではなく**表機能**で作る。
  行・列の追加や幅の調整を人が普通にできる。数字は右揃え、語句は中央揃え。

## 表と図形を重ねるとき（ガント）の注意

**セルの中で文字が折り返すと、その行だけ高くなり、上に重ねた図形とずれる。**
実際に「Rainforest」が2行になり、バーが1行ぶんずれた（2026-09-20）。

- 対策：**属性列の幅を中身の文字量から計算する**（`scripts/build_tables.py` の `text_w()`）。
  全角を1文字、半角を 0.55 文字として見積もり、いちばん長い値に余白を足した幅にする。
- PowerPoint の表には「折り返さない」設定が無いので、**幅で防ぐしかない**。
- もう一つの手：文字を短くする（「Rainforest」→「RF社」）。ただし人が後から長い名前を入れると再発するので、幅の計算のほうが安全。
- 行の高さを変えたら、バーの y 座標も同じ値から計算すること（両方が同じ `row_h` を見ている状態を保つ）。
