# キービジュアル

- **表紙だけ写真のような絵**にしている。挿絵・図解はフラットなイラストのまま。
  理由：表紙は資料の顔なので、ここだけ質感を変えても他の面と喧嘩しない。
- 同梱：`kv_photo_c_lookup.png`（木を見上げる構図）。画像生成モデルで作ったもので、
  作り直す手順は `scripts/gen_keyvisual.py` にある。
- **差し替えるときの条件は「余白の位置」**。表題とロゴが乗る側（この例では左）が空いていれば、
  絵柄は何でも構わない。逆に全面に主題があると、表題が絵に埋もれてレイアウトが破綻する。
- キービジュアルを使わないときは、レイアウトの `kind:"picture"` を `kind:"rect"` に替える
  （PLAYBOOK §3-8）。
