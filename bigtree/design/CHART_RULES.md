# グラフの作法

> デザイン（色・文字）は `TOKENS_OFFICE_THEME.md`、数値の書き方は `CONTENT_RULES.md`。ここは**どのグラフをいつ使うか**の運用ルール。
> SSOT はこの md ＋ `scripts/build_charts.py`（Figma にグラフ機能が無いため。`SSOT_MAP.md` 参照）。2026-09-20 決定。

## 1. 棒と折れ線の使い分け

| | 使うとき | 軸 |
|---|---|---|
| **棒** | **量を比べる**。カテゴリ別（チャネル別・記事別）、時系列でも4〜8点まで | **必ず 0 から始める** |
| **折れ線** | **推移の形を見る**。8点以上の時系列、率（CVR・スキ率・ROAS）の動き | 0 起点でなくてよい |

迷ったときの目安：**その数字を足し算できるか**。
足せる量（セッション・売上・PV）＝棒、足せない率（CVR・ROAS）＝折れ線。

## 1-2. 2時点の対比（前年比・前後比較）

**横棒の集合棒（`kind="barh"`）で作る。図形で描かない。**
比較する数字はデータなので、Excel を直せば済む形にしておく（Organism O-B23 は見本としての参考）。

- 項目名が日本語のときは**横棒**のほうが読みやすい（縦棒だとラベルが折り返す）
- 並びは**上から読める順**にする（軸を逆向きにする。既定は最初の項目が一番下）
- 色は**古いほうをグレー（accent4）、新しいほうを accent1**。自動配色だと古いほうが目立つことがある
- 項目は6つまで。それ以上は上位だけにして「その他」にまとめる

## 2. 複合グラフ（棒＋折れ線・2軸）

**「量と率をセットで見せたいとき」だけ使う。** 型を固定して誤読を防ぐ。

- **棒が量、折れ線が率**（逆にしない）
- 系列は**棒1・折れ線1の2つまで**
- **両方の軸に単位を書く**（`セッション（件）` / `CVR（%）`）
- 折れ線を強調色（accent6）、棒はグレー寄りにして主従をはっきりさせる
- 3系列以上でこの形にしたくなったら、**グラフを2枚に分ける**

## 3. 値ラベル

**軸の目盛りと値ラベルは、どちらか一方だけ。** 両方あると数字が二重になり目が散る。

| 場面 | ルール |
|---|---|
| 棒・カテゴリ6個以下 | **値ラベルを付け、縦軸の目盛りを消す** |
| 棒の中に置くラベル（100%積み上げなど） | **塗りの明るさで白/黒を決める**（`label_on()` が tokens.json の色から自動判定。相対輝度 0.18 が境目） |
| 棒・7個以上 | 軸の目盛りだけ。ラベルは付けない |
| 折れ線 | **最初と最後の点だけ**。または強調している系列だけ |
| 強調した要素 | 系列・点によらず**必ずラベルを付ける** |

ラベルの書式は `CONTENT_RULES.md` に従う（軸・ラベルは K / M、本文と表は桁区切り）。

## 4. 構成比

**100% 積み上げ横棒が基本。**

- 面積より長さのほうが正確に読める
- 内訳が4つ以上でも破綻しない
- 横に並べれば「構成比の推移」も同じ形で見せられる

**円グラフは3要素以下のときだけ**。「全体の中の1つ」を示す場面に限る（例：検索が 58%）。ドーナツは使わない。

## 4-2. 増減の内訳（ウォーターフォール）

**「合計がどう動いたか」を分解して見せるときに使う。** 売上・セッション・費用の前月差など。

- **積み上げ棒＋透明な土台**で作る（`build_charts.py` の `kind="waterfall"`）。ネイティブグラフのまま扱える
- 入力は `steps=[(ラベル, 値, 種別)]`。種別 `"total"` は 0 から積む柱（始点と終点）、それ以外は増減
- 色は**増加＝accent1／減少＝グレー（accent3）／合計＝濃色**。増減で色を変えるのはここだけの例外
- 値ラベルは棒の中（白抜き）。縦軸の目盛りは消す
- **作り方は2種類ある。標準は `kind="waterfall-x"`（chartEx＝Excel 純正）**
  連結線・増加／減少の色分け・合計指定が形式の機能として入っており、Excel でも同じ形で編集できる。
  `kind="waterfall"` は積み上げ棒＋透明な土台で作る互換版（古い環境や、他ツールへの持ち出し用）
- 互換版は **縦軸を 0 起点にしない**（§1 の例外）
- **使い分けは「どこで開くか」で決める。**

| 渡し先 | 使う形 |
|---|---|
| PowerPoint / Word / Excel で開いてもらう | **chartEx 版**（`waterfall-x`）。連結線が付く |
| Google Slides に持ち込む、古い Office の可能性がある | **互換版**（`waterfall`）。積み上げ棒なのでどこでも開く |

Google Slides での chartEx の表示は**確認しない**（2026-09-20 決定）。
新しい形式ほど他ツールの対応はまちまちで、追いかける手間に見合わない。
**持ち出す可能性がある資料では、はじめから互換版を使う**ことで避ける。。0 から描くと増減が数 px に潰れ、ラベルも読めなくなる。
  棒が「量」ではなく「差」を表すグラフなので、下限は最小の到達点より少し下に取る（自動計算）
- 項目は**始点・終点を含めて8本まで**。それ以上は「その他」にまとめる

## 5. 強調

- **1枚につき1か所**。色は **accent6（オレンジ）**
- 強調の単位は「**系列全体**」か「**1つのデータ点**」。両方はしない
- 強調していない系列はグレー3段（accent3〜5）
- **凡例より、線や棒の横に直接ラベルを置く**ほうを優先（目線の往復が減る）

## 6. 共通の見た目

| 要素 | 決まり |
|---|---|
| 目盛線 | **横だけ**、accent5 の細線。縦の目盛線は引かない（**横棒・100%積み上げでは目盛線そのものを出さない**。値軸が横を向くため） |
| 軸線 | 横軸だけ細く（tx2）。縦軸線は引かない |
| 凡例 | 下・中央。直接ラベルを置いたときは凡例を消す |
| 文字 | 軸・凡例・ラベルは「補足」サイズ（PowerPoint 11pt） |
| 系列の色 | **指定しない**（テーマの accent1 → accent2 → グレーの順に自動で付く）。強調だけ accent6 を明示 |
| グラフ枠 | 塗りも枠線もなし |

## 7. データの持ち方（既出）

- **ネイティブグラフ**で作る。横に Excel（`data1 / graph1 …`）を書き出し、**Excel が正**。
- 資料内のグラフにも `graph1` などの名前を付け、`scripts/check_chart_drift.py` でずれを検出できるようにする。
