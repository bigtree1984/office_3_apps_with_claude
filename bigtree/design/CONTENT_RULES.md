# 文書作法（書き方の決まりごと）

> デザインシステム（色・レイアウト）とは別の層。**資料の中身をどう書くか**の決まりごと。
> スライド・Word 文書・グラフの軸・表のセル、すべてに効く。**Claude は資料を作る前にこれを読む。**
> SSOT はこの md（`design/SSOT_MAP.md` の「文章・規則は md が正」に従う）。2026-09-20 初版。

---

## 1. 数値

**桁区切りと K / M 表記を場面で使い分ける。**

| 場面 | 書き方 | 例 |
|---|---|---|
| 本文・表のセル | **そのまま桁区切り** | `12,480` `3,560` `1,204,800` |
| グラフの軸・凡例・KPI の大見出し | **K / M 表記**（場所が狭いため） | `12.5K` `1.2M` |
| 1万未満 | どちらの場面でも**そのまま** | `5,200` |

- K = 千、M = 百万。**10,000 以上で K、1,000,000 以上で M** に切り替える。
- K / M の小数は**1桁まで**（`12.5K`、`1.2M`）。整数で足りるなら付けない（`12K`）。
- 同じ図の中で表記を混ぜない。軸が K なら、その図のデータラベルも K。
- 「万・億」は使わない（K / M と混在すると読み手が換算を強いられる）。

### 割合・増減

| 種類 | 書き方 | 例 |
|---|---|---|
| 割合 | `%`（半角、数字との間は空けない）。小数**1桁**まで | `2.4%` `58%` |
| 比率での増減 | `前月比 128%` のように基準を明記 | `前月比 128%` |
| 割合そのものの増減 | **pt（ポイント）**を使う。% では書かない | `+0.3pt`（2.1% → 2.4%） |
| 倍率 | `1.6 倍` | |

### 単位

- 単位は**軸ラベルや列見出しにまとめる**（`セッション（件）`）。各値に付けない。
- 金額は `¥` を使わず `円`。列見出しに `（円）`、本文では `12,000円`。
- 数字と全角文字の間は空けない。半角英字と日本語の間は**半角スペース1つ**（`PV が 2,140`）。

## 2. 日付・期間

| 場面 | 書き方 | 例 |
|---|---|---|
| データ・英語・ファイル名 | `YYYY/MM/DD` | `2026/09/20` |
| 日本語の文章・表紙 | `YY年M月D日` | `26年9月20日` |
| 年度が文脈から明らかなとき | `M月D日` | `9月20日` |
| 曜日が重要なとき | `M月D日(曜)` | `7月3日(水)` |
| 週次データ | `W38` のような週番号（凡例に基準を注記） | `W38（9/15〜9/21）` |

- 期間は波ダッシュではなく `〜`（例：`9/15〜9/21`）。

## 3. 文末・語調

**体言止めをメインにする。** 媒体ごとの細かい調整は、使いながら決める。

| 要素 | 書き方 |
|---|---|
| **スライドタイトル** | **体言止め**。かつ**論点・問いかけのレベル**で書く。状態や結論は書かない |
| リード文 | 結論・状態を1行で（ここで言い切る） |
| 本文・箇条書き | 体言止めを基本。説明が必要なときは常体（〜である） |
| キャプション・注記 | 体言止め |

### スライドタイトルの考え方（重要）

タイトルは「何の話か」を示す**見出し**であり、結論ではない。結論はリード文に置く。

| ✗ 結論を書いている | ✓ 論点で書く |
|---|---|
| PV は前月比 128%、スキは 1.6 倍に伸びた | PV とスキの伸び方 |
| 楽天RPP への配分を増やすべき | 広告費をどこに寄せるか |
| 連載 #3 が最も読まれた | 記事ごとの読まれ方 |

→ タイトルで論点を示し、リード文で答える。読み手は「何の話か」を先に把握できる。

## 4. 用語

- 表記を統一する：`Web`（ウェブと書かない）、`ユーザー`（ユーザと書かない）、`note`（小文字）、`PV` `CVR` `ROAS` は大文字。
- 初出の略語には、かっこで正式名称を添える（`ROAS（広告費用対効果）`）。2回目以降は略語のみ。
- 社名・サービス名は正式表記。

## 5. 強調

- **1枚（1ページ）につき1か所**。強調が2つ以上あると強調でなくなる。
- 色は必ず **accent6（オレンジ）**。自動配色には入っていないので、指定したときだけ出る。
- 文字の強調は文字スタイル「強調」で当てる。直接の色指定はしない。

## 6. 図表

- 図は「図 N：説明」、表は「表 N：説明」。番号は自動採番（Word）／手動（PowerPoint）。
- 出典・注記はキャプションのあとに `※` で添える（`※ 数値はダミー。税抜・速報値`）。
- グラフは、伝えたい系列だけ色を付け、残りはグレー（`design/TOKENS_OFFICE_THEME.md` の色塗りポリシー）。

## 7. ファイル名

`YYMMDD_相手_内容.pptx` の形（例：`260920_morikawa_ec_report.pptx`）。日付は先頭に置き、並べ替えで時系列になるようにする。
