# Word スタイル表（SSOT）

> **この文書は【既定】です。** スタイルの構成（表題・見出し・本文・キャプション・表）は
> そのまま使えますが、サイズや間隔は利用者の好みで変えて構いません。
> **日本語 Word の行間対策（行間を固定値にする）だけは【変えない】**。
> **理由：日本語 Word は既定で行を文字グリッドに吸着させるため、外すと行間が倍近く開きます**
> （`notes/TEXT_LAYOUT_NOTES.md` §9・§10）。好みの問題ではなく、Word の挙動への対処です。

> `design/SSOT_MAP.md` のとおり、**Word のスタイルはこの md が正**。色とフォントは Figma のトークン（`design/tokens.json`）を参照する。
> 値の機械可読なコピーは `design/tokens.json` の `type_docx`。スクリプトは `scripts/build_dotx.py`。
> 確定 2026-09-20。Figma は「04 Word見本帳」ページに、見本 DOCX を PDF→画像で並べる（見本帳）。

## 文字サイズ（本文 10.5pt を基準に、比率 1.2）

| スタイル | サイズ | ウェイト | 行間 | 段落前 / 後 | 色 |
|---|---|---|---|---|---|
| 表題（Title） | 24pt | Bold | 130% | 0 / 6pt | 墨 dk1 |
| 副題（Subtitle） | 13pt | Regular | 150% | 0 / 24pt | 淡墨 dk2 |
| 見出し1 | 18pt | Bold | 140% | 24pt / 6pt | accent1（green） |
| 見出し2 | 15pt | Bold | 140% | 18pt / 6pt | 墨 dk1 |
| 見出し3 | 12.5pt | Bold | 140% | 12pt / 6pt | 墨 dk1 |
| 本文（Normal） | 10.5pt | Regular | 170% | 0 / 8pt | 墨 dk1 |
| キャプション | 9pt | Regular | 150% | 3pt / 12pt | 淡墨 dk2 |
| 表内テキスト | 9.5pt | Regular | 140% | 0 / 0 | 墨 dk1 |

- PowerPoint（本文 14pt・比率 1.25）とは別に決めた。Word は画面で読む前提で、段階の差も小さくする。
- **行間は pt 指定**（`w:lineRule="exact"`）。Word の「倍数」指定は PowerPoint の％と同じく font 依存で広がる（`reference/TEXT_LAYOUT_NOTES.md`）。
- **例外：「図」スタイルだけ行間を auto にする**。固定値にすると**行内の画像がその高さに切り詰められて消える**（実際に挿絵が消えた）。

| 部分 | 見た目 |

| 見出し行 | accent1 の塗り＋白の太字 |

| 1列目 | 太字 |
| セル余白 | 左右 120 / 上下 80 twips |

## 表紙と目次（2026-09-20 追加）

- **表紙**：入力枠（コンテンツコントロール）5つ。PowerPoint の表紙と同じ項目。
  区分 ／ 宛先 ／ タイトル ／ サブタイトル ／ 日付・作成者。テンプレートから新規作成すると案内文の状態で並ぶ。
- **目次**：見出しスタイルから自動生成（`TOC` フィールド）。**見出し1〜2まで**。
  ページ番号は出さない（Web レイアウト表示のため）。クリックで本文へ飛べる。スタイルは「目次1・2」。
- **`<w:updateFields>` は入れない**：開くたびに「他のファイルを参照するフィールドが含まれています」という
  分かりにくいダイアログが出るため。目次の中身は Claude が文書生成時に書き込む。人が見出しを足したときだけ
  右クリック →「フィールド更新」。

## そのほかの決定（既出）

- 表示は Web レイアウト（改ページなし）。余白・ヘッダー・フッターは印刷／PDF 用。
- ドキュメントグリッド無効、段落間隔で区切る（空行を使わない）、1字下げなし、見出し番号は自動採番。
- 画像は行内配置＋「図」スタイル（中央揃え）＋キャプションの図表番号。
- フォントは Noto Sans JP の Regular と Bold のみ（Black は使わない）。
