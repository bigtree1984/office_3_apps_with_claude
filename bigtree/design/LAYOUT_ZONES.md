# ボディゾーン レイアウト（Layout）

> **ここの考え方は【変えない】**（本文をゾーンに分け、その中に図解を置く）。
> **理由：図解の種類ごとにレイアウトを作ると、種類が増えるたびにテンプレートが増えて管理できなくなるため。**
> ゾーンを決めておけば、同じ本文レイアウトの上に何種類でも図解を置けます。
> **個々のゾーンの寸法は【たたき台】**で、利用者のレイアウトに合わせて決め直してください。

> 【0304】`260911 Slide Design System KP` の「② Slide Layout」で定義した9種を、今回の本文枠に移植したもの（2026-09-20）。
> **Layout は Organism の置き場所を決める補助レイヤーであり、それ自体は意味を持たない**（0304 の定義を継承）。
> 値は `design/layouts.json`（スクリプトが読む）。Figma の「02 PowerPoint」ページに `layout-zone/*` として見本を置いた。

## セーフゾーンとガイド

**考え方は【変えない】／数値は【たたき台】。**

スライドの端まで要素を置かず、**周囲に触らない帯（セーフゾーン）を決めて、そこにガイドを引く**。
**理由は3つ**あります。

1. **人がスライドを編集したときに、位置が揃う。** ガイドは PowerPoint 上で吸着するので、
   あとから人が図を足しても、端の位置が勝手に揃います。**ルールを覚えていなくても守られる**のが肝です
2. **投影・印刷で端が切れても、中身が欠けない**
3. **エージェントが座標を決めるときの基準になる。** 「本文はセーフゾーンの内側」と書いておけば、
   毎回の判断がぶれません

この一式の数値（1440×810px のフレーム内。**2px = 1pt**）:

| | 値 | pt |
|---|---|---|
| 左右 | 72px | 36pt |
| 上 | 48px | 24pt |
| 下 | 34px（ガイドは Y=776） | 17pt |

下が狭いのは、著作権表示とページ番号を**セーフゾーンの外側に置いている**ためです（中身ではないので、
端に寄せて本文の面積を稼いでいます）。

レイアウトごとに、これとは別の**基準線**も引いています（例：表紙は画像の境目 X=680、扉はタイトルの基準 Y=405）。
こちらは完全に【たたき台】で、自分のレイアウトに合わせて引き直してください。
データは `design/figma_layouts.json` の `master_guides`（全レイアウト共通）と、各レイアウトの `guides`。

## 前提となる本文枠

| 使うレイアウト | 本文枠（px） |
|---|---|
| 06 本文（リードあり） | `72, 216` / **1296 × 512** |
| 07 本文（リードなし） | `72, 152` / **1296 × 576** |

ゾーン間の間隔（GAP）は **32px**（＝16pt）。0304 は 1920px 幅で GAP 40px だったので、縮尺に合わせて 8 の倍数に丸めた。

## 9種類（リードありの場合のゾーンサイズ）

| ID | 分割 | ゾーン |
|---|---|---|
| L-1 | Full（1ゾーン） | A 1296×512 |
| L-2H | 左右2分割 50/50 | Left / Right 632×512 |
| L-2H-4060 | 左右2分割 40/60 | Left 506×512 ／ Right 758×512 |
| L-2H-6040 | 左右2分割 60/40 | Left 758×512 ／ Right 506×512 |
| L-2V | 上下2分割 50/50 | Top / Bottom 1296×240 |
| L-3H | 左中右3分割 | L / C / R 411×512 |
| L-4 | 2×2の4分割 | TL / TR / BL / BR 632×240 |
| L-2H-Rs | 左右2分割・右だけ上下分割 | Left 632×512 ／ RT・RB 632×240 |
| L-2H-Ls | 左右2分割・左だけ上下分割 | LT・LB 632×240 ／ Right 632×512 |

リードなしの版は、`y=152` から始まり高さが 576 になる（上下分割のゾーンは 272 高）。両方の座標が `layouts.json` に入っている。

## 使い方（Claude 向け）

1. 伝えたい情報構造から **Organism** を選ぶ（`ORGANISM_INVENTORY.md`）。
2. Organism を1つだけ置くなら **L-1**。2つ並べる・図と文章を並べるなら 2分割系を選ぶ。
3. 選んだゾーンの座標（`layouts.json`）に合わせて、Organism の幅・高さを縮める。
   - Organism は幅 1296px で作図してあるので、半分のゾーン（632px）に置くときは作図し直すか、要素数を減らす。
4. **1スライドに Organism は原則1〜2個**。3個以上並べたくなったら、スライドを分ける。
