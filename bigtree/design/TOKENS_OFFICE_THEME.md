## 色塗りポリシー（芝野さん）

- 伝えたいことは1つか2つ。**有彩色はその1〜2個だけ**。残りはグレースケールでよい。
- 12系列を有彩色で塗り分ける必要はない。
- （予備）どうしても多色が必要なら、HLS の色相を12分割して 1→6→11→4… と飛ばして選ぶ。
  ただし色相だけだと明るさが揃い、白黒で同じになる → **色相を飛ばすと同時に明るさも交互に変える**。

## 割り当て（並び順＝Office が自動で塗る順番）

| 枠 | 値 | 役割 |
|---|---|---|
| dk1 | 墨 `#1F4437` | 基本の文字 |
| lt1 | 地 `#FFFFFF` | 基本の背景 |
| dk2 | 淡墨 `#66776F` | 補助の文字 |
| lt2 | 面 `#F7F4EE` | 補助の背景 |
| accent1 | 対比A green `#2F6B55` | 重要1（有彩色）。図形の既定の塗り |
| accent2 | 対比B sand `#FFCB68` | 重要2（有彩色） |
| accent3 | グレー濃 `#66776F`（淡墨） | 残り |
| accent4 | グレー中 `#94A09A`（淡墨を白へ 30%） | 残り |
| accent5 | グレー淡 `#C2C9C5`（淡墨を白へ 60%） | 残り |
| accent6 | 主役 accent `#E2773A` | **自動では使わない**。意図して強調するときだけ |
| hlink / folHlink | green / 淡墨 | リンク |

→ 人が PowerPoint で普通にグラフを挿入しても、系列1・2は有彩色、3〜5はグレーになる。**ポリシーがテンプレートに組み込まれる**。

## グレー3段の根拠（明るさ L* と白地とのコントラスト比）

| | 値 | L* | 白地との比 |
|---|---|---|---|
| グレー濃 | `#66776F` | 48.5 | 4.74 |
| グレー中 | `#94A09A` | 64.8 | 2.71 |
| グレー淡 | `#C2C9C5` | 80.3 | 1.69 |

- 3段の L* の差がほぼ等間隔（約16ずつ）→ 白黒でも段階として見分けられる。
- 淡墨から作るので、わずかに緑を帯びたグレー。Bigtree Lab の色調（墨＝深緑）と揃う。新しい色相は足していない。
- 注意：白黒印刷では green（L* 40.9）とグレー濃（48.5）、sand（84.5）とグレー淡（80.3）が近い。
  カラーでは色相が違うので問題ない。白黒前提の資料では、グレーを使う系列を減らす。
